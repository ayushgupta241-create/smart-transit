About TransitScrum

A small public transport information service, built with Scrum and delivered through a DevSecOps pipeline.

How it supports SDG 9

  • Innovation: live arrivals and vehicle positions give commuters data they can act on.
  • Infrastructure: the hosting is described as code (Terraform), so it can be rebuilt the same way every time.
  • Reliability: a health endpoint, automated tests and a repeatable container image catch problems before users do.
  • Security: code and images are scanned on every build, and the app sends strict security headers.

DevSecOps workflow

  1. Commit to GitHub.
  2. Jenkins runs the unit tests.
  3. SonarQube analyses the code; Trivy scans dependencies and Terraform.
  4. Jenkins builds the Docker image; Trivy scans the image.
  5. The image is deployed to the AWS server that Terraform created.
